제품 가치

각 가치의 전체 정의와 경계는 values.md에 있다.

V1 · 자연어로 클러스터 운영kubectl 을 직접 쓰지 않고 조회·진단·재시작·스케일을 의도만으로 수행한다.
V2 · 단명·최소권한 자격증명장수 키를 들고 다니지 않고 필요한 순간에 짧은 수명의 스코프된 자격증명을 받는다.
V3 · 안전한 운영 (Safe-by-default)무인증 접근·의도치 않은 파괴·미설정으로 인한 서버 다운이 기본값으로 막힌다.
V4 · 운영 지식의 축적·검색운영하며 알게 된 것을 쌓고 다시 찾아 쓴다.
V5 · 클러스터 내부 앱 기능의 도구화앱을 외부에 열지 않고, 도구로 명시한 동작만 좁게 연다.
