homelab-k3s-mcp

홈랩 k3s 클러스터와 연결된 클라우드 리소스를 AI 어시스턴트로 운영하는 MCP 서버. 이 사이트는 그 제품 가치와, 가치에서 내려온 도구별 PRD·테스트 문서의 진입점입니다.

레포지토리 README (설치·인증) 문서 체계 상태 E2E 모킹 정책

제품 가치

모든 문서의 최상위 판단 기준. PRD와 테스트 문서는 각각 자신이 어떤 가치를 달성하고 검증하는지를 이 다섯 가지로 밝힙니다. 가치 문서 전문 읽기

  • V1 자연어로 클러스터 운영 kubectl을 직접 쓰지 않고 조회·진단·재시작·스케일을 의도만으로 수행한다.
  • V2 단명·최소권한 자격증명 장수 키를 들고 다니지 않고, 필요한 순간에 짧은 수명의 스코프된 자격증명을 받는다.
  • V3 안전한 운영 (Safe-by-default) 무인증 접근·의도치 않은 파괴적 동작·미설정으로 인한 서버 다운이 기본적으로 막힌다.
  • V4 운영 지식의 축적·검색 흩어진 운영 지식을 한 곳에 모아 같은 문제를 두 번 풀지 않게 한다.
  • V5 클러스터 내부 앱 기능의 도구화 앱을 외부에 열지 않고, 도구로 명시한 동작만 좁게 연다.

문서 체계 상태

가치 → PRD → Acceptance Criteria → 테스트의 연결이 끊긴 곳이 없는지, 각 AC가 실제 자동화로 검증되고 있는지를 추적합니다. 문서를 만들거나 고칠 때 함께 갱신합니다. 상태 추적 문서 읽기

이 사이트는 main 브랜치의 docs/ 를 GitHub Pages로 그대로 서빙합니다. 문서를 추가하면 이 페이지에 한 줄을 함께 추가해야 진입점에서 도달할 수 있습니다.

로컬에서 확인할 때는 cd docs && python3 -m http.server 로 띄웁니다 (뷰어가 fetch를 쓰므로 file://로 직접 열면 열리지 않습니다).
