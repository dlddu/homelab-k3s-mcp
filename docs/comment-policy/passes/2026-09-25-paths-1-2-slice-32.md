**⑹** 「Walks the AC's verification method clause by clause: the first write of an explicit id reports
``created``; re-putting that id reports ``updated`` and the *new* body is what a later search returns
…; two id-less writes … come back ``created`` with two different auto-generated ids …」 ↔ PRD AC1
**검증 방법** 「최초 색인은 created, 같은 id 재색인은 updated가 반환되고 이후 검색에서 새 본문이
조회된다. id 미지정 호출은 서로 다른 자동 id를 받는다」. 주석이 스스로 「Walks the AC's verification
method」 로 **그 AC 를 SSOT 로 지목한다**.

괄호 해설 둘은 PRD 밖이라 **따로 물었고 둘 다 ① 로 닫혔다** — 같은 함수 안의 실패 메시지가 원본이다:

* 「(so the second write replaced the document instead of adding a second one)」 ↔
  `search_until(…, "doc-1 is a single document carrying the second body")`
* 「and leave three documents behind, not two.」 ↔
  `search_until(…, "the upsert plus both auto-id writes leave exactly three documents")` +
  `assert final["total"] == 3`

**함수 안의 FAIL 메시지는 ① 원본이다** — 실패했을 때 사람이 읽는 자리이고, 주석과 달리 어서션과 함께
낡는다.
