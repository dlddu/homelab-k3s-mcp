# 2026-09-14 — 시나리오 2·4 전용 e2e 둘 (`tests/integration/resource_generic_ac2.py` · `resource_generic_ac4.py`)

판정 근거: `rct_20260914-0004`(정합성 모델 `tbm_homelab-k3s-mcp-comment-redundancy`).
원장 행: 줄 주석 #28, docstring #10.

PR #79(`rct_20260914-0002` — 시나리오 2·4 전용 e2e)가 신규 파일 둘로 주석 **59줄**
(줄 주석 9 + docstring 50)을 들여오면서, 판정 대신 **잔량 마커**를 올렸다. 직전 패스
(`2026-09-14-resource-read-axis.md`)가 잔량을 양 표면 모두 0 으로 닫은 **직후**의 유입이고,
그 사실 자체가 원장이 적어 둔 대로다 — 「잔량 0 은 「끝났다」가 아니라 「지금 여기서 다시
시작한다」는 뜻이다」. 이 패스가 그 인계를 받는다.

**게이트는 유입 전후 양 지점에서 rc=0 이었다.** R4·R8 은 `합계 + 잔량 == 실측` 만 강제하고
잔량을 올리는 것이 적법한 순응 경로이기 때문이다. 초록은 「판정이 끝났다」를 뜻하지 않는다 —
래칫은 *은폐를 막는* 장치이지 *판정을 강제하는* 장치가 아니다.

### 판단이 갈려 유지한 것

정책 §「애매하면 남긴다」에 따라 보존하고, 갈렸다는 사실을 여기 남긴다. 다음 판정의 입력이다.

1. **함수 docstring 요약 줄 5개의 「시나리오 N — …」 형태.** 함수명 + 시나리오 기대 결과를
   되풀이하므로 ② 경계다. 그런데 절차 2번이 그 자리를 관례 최소 doc 으로 정하고, **같은 날
   원장 docstring #9 가 `resource_read_smoke.py` 의 같은 형태를 「관례 최소 요약」으로
   유지**했다. 같은 축·같은 주에 갈린 결론을 남기지 않기 위해 선례를 따랐다. 이 형태를
   제거 쪽으로 옮기려면 `resource_read_smoke.py` 행과 **함께** 재판정하는 것이 맞다.
2. **`ac2` 모듈 ¶4 의 AC17 절** — 「AC17 이 list 를 게이트 밖에 두는 근거가 바로 「표에는 값이
   실리지 않는다」이므로」는 `docs/prd-resource-generic.md` 로 도달한다. 그러나 뒤 문장
   (「이 축은 크기가 아니라 형태로 지켜져야 한다」)이 **AC 가 테스트 형태에 부과하는 제약**이라
   전제를 잘라내면 논증이 끊긴다 — 원장 #9 이 AC4 전제에 내린 것과 같은 처리다.
3. **`ac2` `#: _DUMP`** 와 **`ac4` 의 「빈 맵을 키째 지운다」** — 위 줄 주석 표 참조.

## 판정 절차 4번은 발화하지 않았다

「원본이 부실해서 복원이 안 되면 주석을 남기는 대신 **원본을 고친다**」는 4번을 ② 두 건에
대해 재 봤다. `docs/test-resource-generic.md` 의 시나리오 2 실행 단계·기대 결과, 시나리오 4
사전 조건·기대 결과, 「픽스처」 절을 주석 문면과 한 줄씩 대조했고 — **주석이 문서보다 더
정확한 자리는 없었다.** 주석은 문서를 정확히 인용하고 있었을 뿐이다. 그래서 이 패스는
시나리오 문서를 고치지 않는다.

## 부수 정정 — 원장 산문 한 줄

`ledger.md` 의 docstring `0 → 50` 항목이 「바로 위 항목이 잔량을 0 으로 닫은 직후 다시 **45**
가 선다」로 적고 있었으나 실측은 **50** 이다(같은 항목의 머리·`<!-- docstring-잔량 -->`
마커·게이트 출력·독립 계수 `ac2` 19 + `ac4` 31 이 전부 50). **마커와 산술은 처음부터
정상이었고 낡은 것은 그 산문 한 줄뿐이다** — `87 → 0` 항목의 「열거 산문만 불완전」과 같은
계열이라 독립 gap 으로 올리지 않고, 어차피 이 표면을 다시 쓰는 이 패스에서 맞췄다.

## 이 패스가 남기는 것

- 두 표면이 다시 **잔량 0**(줄 주석 1297/1297 · docstring 1066/1066). 원장 머리말이 적은 대로,
  0 은 종점이 아니라 **다음 유입이 즉시 걸리는 상태**다.
- 이번 인계는 유입(#79, 06:12Z)에서 판정까지 **같은 날 안에** 닫혔다 — 직전 사례
  (`0 → 87` → `87 → 0`)에 이어 래칫이 한 바퀴 돈 **두 번째** 기록이다.
- 제거로 줄 주석 지문이 움직이므로(`25bbaf40e199…` → 실행 후 재계산) 모델의 재감지가
  뒤따른다. 이 패스의 범위는 위 두 행이고, 그 밖의 잔여는 재감지가 새 task 로 잇는다.
