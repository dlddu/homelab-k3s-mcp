## 유지 (사유 한 문장)

Go 관례 최소 doc(exported 식별자 첫 문장·패키지 주석)은 사유를 따로 대지 않는다. 아래는 필요성 시험으로 남긴 것이다.

- telemetry — 패키지 주석의 OBI 1024바이트 창 사유(지우면 SDK 가 중복으로 보여 제거된다), 트레이싱이 옵트인이며 엔드포인트가 없으면 no-op 이라는 것, OTLP 내보내기 요청이 래퍼에 안 잡히는 이유, `KubeTransport` 를 exec·attach·port-forward 에 쓰면 SPDY 업그레이드가 깨진다는 함정, `AWSTracerProvider` 를 `Setup` 뒤에 불러야 하고 AWS SDK 가 `http.DefaultTransport` 래퍼를 타지 않는다는 것.
- drop — 토큰 파일 위치가 `k8s/deployment.yaml` 의 projected 볼륨과 짝이라는 것, 한도 상수가 drop 의 API 와 같아야 하고 라벨 40자가 운영 접두사 35자 때문이라는 수치 근거, 45초 타임아웃의 Sablier 콜드스타트 근거, 요청 본문을 `bytes.NewReader` 로 만드는 이유(307 재시도에서 본문이 사라져 기본값으로 발급된다), `tokenFile` 을 호출마다 다시 읽는 이유, 예시 보관 일수를 토큰 `max_days` 로 낮추는 이유(400), 토큰 원문을 setup 한 줄에만 싣는 이유, kind 픽스처가 운영과 갈리는 지점과 이미지 SHA 핀 절차, TokenReview 바인딩 부재 시 502, Go 소수 초 9자리와 Python `fromisoformat` 의 불일치.
- opensearch — 요청 타임아웃 45초의 두 백엔드 콜드스타트 근거, 백엔드가 docstore 와 OpenSearch 둘 다라는 것과 인증이 설정이라는 것, `not_found` 계약, `Serverless` 가 payload 해시 헤더를 요구한다는 상류 동작, 307 재생 테스트의 사유, 인증 모드 선택 규칙(둘 중 하나만 설정하면 오류).
- mcp — `defaultSensitiveKind` 가 `RESOURCE_GATED_KINDS` 기본값과 맞물린다는 것, 게이트·리더가 nil 이 아니라는 불변식과 별도 옵션인 이유(독립 실패), 레지스트리를 핸들러가 쥐는 이유, 호출 기록이 `toolsCall` 한 곳에서만 쓰이는 이유, `reasonOf`·`afterVerdict`·`gateRefusal`·`outcome` 의 분류 사유, 빈 목록과 도달 불가를 가르는 이유, 스냅샷된 세션의 `pod` 누락 처리.
- k8s — 이벤트 수집 라벨 이름을 바꾸면 조회 셀렉터가 끊긴다는 것과 서버에 Loki sink 를 두지 않는 이유, deploy 브랜치가 운영 값의 출처라는 것과 `imagePullPolicy` 기본값이 옳은 이유, env 가 Secret 키를 이긴다는 것, PocketAide·drop 등록이 없으면 401·403 으로 거부된다는 것, 토큰 audience 가 상대와 같아야 하고 기본 토큰을 보내지 않는 이유, base 를 소비하는 세 곳과 `images:` 변환을 두지 않는 이유.
