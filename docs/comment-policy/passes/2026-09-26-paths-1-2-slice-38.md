전수 그렙으로 재확인했다. 그래서 선정 기준은 예고대로 **크기·가족(공유 사본)** 이다.

**그 둘을 *함께* 집은 결정적 근거는 크기가 아니다.** 판정 표면 전수에서 각 후보 줄의 바이트 동일

## 제거 7줄 — 전부 ① 코드 자체 재진술

### ⑴ `grafana.go` `112–116` → 1줄 (−4) · ⑵ `github.go` `112–114` → 1줄 (−2)

**이 두 자리는 슬라이스 37 이 `awsconfig` 에서 지운 것과 같은 문면이다.** `github` 쪽은 환경변수
접두사와 `GitHub` 낱말만 다른 **축자 동일**이다:

```go
// (슬라이스 37 이 awsconfig 에서 제거)
// FromEnv builds a Client from the AWS_CONFIG_* environment variables. It
// returns (nil, nil) when AWS_CONFIG_S3_BUCKET is unset, signalling that the
// integration is simply not configured (as opposed to misconfigured).

// (이 슬라이스가 github 에서 제거)
// FromEnv builds a Client from the GITHUB_APP_* environment variables. It
// returns (nil, nil) when GITHUB_APP_CLIENT_ID is unset, signalling that the
// GitHub integration is simply not configured (as opposed to misconfigured).
```

바로 아래 본문이 같은 것을 말한다 — 반환값·환경변수 이름·분기 조건이 세 줄에 전부 있고,
「not configured vs misconfigured」 대비는 **같은 함수의 두 분기**가 그대로 든다:

```go
clientID := os.Getenv("GITHUB_APP_CLIENT_ID")
if clientID == "" {
	return nil, nil                    // 미설정 = 에러가 아니다
}
installationRaw := os.Getenv("GITHUB_APP_INSTALLATION_ID")
if installationRaw == "" {
	return nil, fmt.Errorf("GITHUB_APP_INSTALLATION_ID is required when GITHUB_APP_CLIENT_ID is set")
}                                          // 잘못 설정 = 에러다
```

`grafana` 쪽은 문장이 하나 더 길어 **−4줄**이다. 그 셋째 문장(「When the issuer token is set but a
required companion variable is missing, it returns an error (a misconfiguration) rather than silently
dropping it」)은 같은 함수의 `missing` 루프가 내는 **오류 문면과 축자로 겹친다** —
`fmt.Errorf("%s required when GRAFANA_ISSUER_TOKEN is set", …)`. 즉 주석이 옮겨 적은 것이 곧
그 에러 문자열이다.

정책 「유지 대상 2」 마지막 항 — **「1줄 뒤에 이어지는 문단이 시그니처나 `docs/prd-*.md`를
되풀이하면 그 문단이 제거 대상」** — 에 정확히 걸린다.

### ⑶ `grafana.go` `166–167` → 1줄 (−1)

```go
// CreateToken mints a fresh token under the configured access policy that
// expires one hour from now and returns it alongside the static query config.
```

이어지는 절이 셋 다 ① 로 복원된다 — 「expires one hour from now」 = `tokenTTL = time.Hour` +

`&Credentials{Token, ExpiresAt, MetricsURL, MetricsUser, LogsURL, LogsUser}` 리터럴,

남긴 형태는 관례가 요구하는 1줄이다.

**추가 0줄.** 세 자리 모두 기존 문장에서 `It returns` · `It` · `that` 만 떨어뜨렸고 **새 낱말이
하나도 없다** — 새 주장 0건.

### ② 는 세 자리 모두 무히트

`docs/` 전수에서 이 세 문단의 명제를 찾지 못했다. PRD 는 도구의 입출력 계약을 적고 `FromEnv` 의
