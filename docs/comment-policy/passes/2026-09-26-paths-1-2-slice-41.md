### ⑵ `service.go` `36–38` → `36–37` 2줄 (−1) — 쌍둥이가 이미 걷힌 자리

```go
// ExecResource is the coordinate-addressed half of exec
// (prd-resource-generic AC12): one named pod, one command array, stdout and
// stderr returned separately under AC12's byte and time caps.
```

**① 시그니처 재진술**: `ref ExecRef`(one named pod) · `command []string`(one command array) ·
`*ExecOutcome` 의 `Stdout`/`Stderr`(갈라 담는다) · `StdoutTruncated`/`StderrTruncated`/
`TimeLimited`(두 상한) — 콜론 이하 네 명제가 전부 선언에 있다.

**② 축자 겹침**: AC12 설명 「대상 파드·컨테이너와 명령 배열을 받아 새 프로세스를 띄우고
stdout/stderr를 반환한다 … 출력에는 바이트 상한과 실행 시간 상한을 둔다」 + 검증 방법
「stdout/stderr가 구분되어 반환된다」.

**쌍둥이 실측 — 이 제거는 번복이 아니라 선 판정의 n번째 적용이다.** 2026-09-18
(`rct_20260918-0002`)이 형제 `AttachResource` 의 **같은 자리 본문**을 「① 시그니처 재진술 —
인자가 그대로 말한다」로 지웠다(원장 행 `#6` 의 그 항목에 그대로 남아 있다). 현재 네 스트림
메서드의 모양을 세면:

| 메서드 | 모양 | 본문 |
| --- | --- | --- |
| `ExecResource` | 1줄 + AC 포인터 + **콜론 본문** | ⚠️ **유일한 이탈** |
| `AttachResource` | 1줄 + AC 포인터 | 없음(2026-09-18 제거) |
| `PortForwardResource` | 1줄 + AC 포인터 | 없음 |
| `ProxyResource` | 1줄 + AC 포인터 | 없음 |

⇒ 넷 중 하나만 걷히지 않은 상태였고, 걷는 쪽이 정합이다. **AC 포인터 괄호는 남긴다** — 그것은
재진술이 아니라 소유자 포인터이고, 지우면 중복을 피하던 형태 자체가 사라진다.
