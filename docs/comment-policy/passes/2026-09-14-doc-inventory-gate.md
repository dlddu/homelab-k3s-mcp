## 이번 유입의 특징 — 판정 대상이 게이트 자신이다

앞선 패스들의 대상은 테스트 파일이거나 구현 코드였다. 이번 파일은 **바로 그 PR 에서 CI lint 잡에
등록된 체커 자신**이라 두 가지가 달라진다.

1. **모듈 docstring 을 통째로 걷을 수 없다.** 정책 §유지 대상 2 가 Python 모듈 docstring 을 유지로
   두었고, 이 자리는 「이 스크립트가 무엇을 검사하는가」를 말하는 유일한 곳이다. 판정 대상은
   docstring 의 존재가 아니라 **본문 중 복원되는 절**이다.
2. **실패 메시지가 복원 경로가 된다.** 이 스크립트의 D1·D4 실패 메시지는 규칙의 문면과 기대
   형태를 **축자로 출력**한다. 그래서 같은 내용을 선언부 주석이 다시 적으면 ③ 자기 파일 중복이
   된다 — 그런데 실패 메시지 쪽은 지울 수 없다(게이트의 산출물이다). 따라서 **지울 수 있는 사본은
   주석 쪽**이다. 원장 docstring #1 이 `check_comment_policy.py` 의 규칙 목록을 「실패 메시지
   어디에도 규칙 *집합*은 없다」를 이유로 유지한 것의 **정확한 여집합**이고, 이번 판정의 중심이다.

### 제거 — 축자 인용 블록 (삼중 복원)

모듈 docstring 머리에 doc-tracker 의 대상 줄이 **스키마째 인용**돼 있었다.

```
`docs/doc-tracker.md` 의 「문서 공개」 표에는 이런 줄이 있다.

    | 허브 도달 가능 문서 | ✅ **N / N** (가치 a + PRD b + 테스트 c + 상태 추적 d + 정책 e), 끊긴 링크 0 |
```

세 곳에서 복원된다.

1. **③ 같은 파일의 D4 실패 메시지** — 「형태는 `` | 허브 도달 가능 문서 | ✅ **N / N** (가치 a +

   (`0` 이 `f` 로 일반화된 것만 다르고, 일반화된 쪽이 더 정확하다).
2. **① `CLAIM_RE`** — 같은 형태를 정규식으로 박아 두었고, 그것이 파싱의 실제 계약이다.
3. **② `docs/doc-tracker.md`** — 그 줄 자신이 원본이다.

원장 docstring #10·#11·#12 가 고정한 처리(**인용은 걷고 논증은 남긴다**)를 그대로 적용했다.
남긴 것은 그 줄이 *무엇을 주장하는가*의 분해(⑴ 전부 도달 가능 ⑵ 수와 내역이 맞다)인데, 이것은
인용이 아니라 **뒤 문단의 D2/D4 논증이 서는 전제**다. 문단을 이어 붙이며 인용에 기대던
「종류별 내역이 저렇다는 것」을 「그 수와 종류별 내역이 맞다는 것」으로 고쳤다.

### 유지 — D1~D4 규칙 열거 (선례가 직접 지배한다)

원장 docstring #1 의 문장이 그대로 적용된다: 「규칙 목록은 코드로 복원되는 것처럼 보이지만

`check_comment_policy.py` 의 「정책 문서가 착지하던 날 848줄이라 적힌 사이 형제 PR 로 963 이 됐고

### 유지 — D2·D4 를 함께 두는 이유 3줄

### 유지 — 함수 docstring 요약 줄 4개

`categorize` · `normalize` · `md_links` · `reachable` 의 한 줄 요약. 절차 2번(관례가 요구하는 최소

출력과 그 게이트의 `comment_lines()` · `docstring_lines()` 파일별 재계수에서 뽑았다.

## 이 패스가 처음 치른 비용 — 패스 문서 자체가 허브 집계를 움직인다

이 문서가 `docs/` 에 들어오면서 문서 수가 하나 늘었다. #94 가 세운 `check_doc_inventory.py` 가

올린다**(총계·도달 수·정책 칸 각 +1).

앞선 네 번의 패스 PR 은 이 줄을 건드리지 않았고 — 그것이 정확히 이 게이트가 세워진 이유다 —
**이 패스가 그 게이트에 걸린 첫 패스**다. 게이트는 자기를 들여온 PR 다음에 오는 첫 동종 PR 에서
곧바로 값을 했다. 도달성(D2)도 함께 증명된다: 이 문서는 허브에서 직접 링크되지 않고
`index.html` → `comment-policy/README.md` → `ledger.md` → 아래 원장 행의 링크로 **이행적으로만**
닿는다. D2 가 이행 도달을 세지 않았다면 이 문서는 「도달 불가」로 잡혔을 것이다.
