## 판정 기준 — 슬라이스 1~4 의 구분 그대로

1. **본문이 그 주장을 대신 말하면 지운다.** 본문이 *결과*·*무엇*만 적고 주석이 지는 *이유*·*교차 제약*은 적지 않으면 「다른 주장」.
2. **본문이 스스로 주석을 가리키면 원본은 주석 쪽** — 유지.
3. **본문이 결론을 담더라도 앞으로의 편집을 구속하는 서 있는 불변식이면 유지**(README 3분 표 둘째 줄).

여기에 이 층에서 처음 부딪힌 경계 하나를 적어 둔다. **PR 안의 개별 커밋 메시지는 ③ 도 ④ 도 아니다.** README ③ 은 「PR 제목·본문·
리뷰 코멘트」, ④ 는 「PR 없이 main 에 바로 push 된 커밋」이고, squash 착지된 PR 의 구성 커밋 메시지는 어느 문면에도 없다(`gh api
pulls/N/commits` 로는 닿지만 main 이력에는 없다). `http-trace.yaml` 이 정확히 그 자리다 — 픽스처가 #41 의 **둘째 커밋**(`c45dd784`)

### 제거 — 머리말 「Why this exists」 문단 (10–20행, 구분선 포함 11줄)

```
# Why this exists: the MinIO fixture accepts the base credentials the CI secret
# carries (minioadmin) exactly as readily as assumed-role credentials, and the
# OpenSearch fixture runs with the security plugin disabled, so it accepts
# signed and unsigned requests alike. A server that never assumed a role would
# therefore pass every outcome-based e2e assertion in tests/integration --
# making those assertions vacuous with respect to
# aws-config-get/AC2 and opensearch-{search/AC3,document-put/AC4,
# document-delete/AC4}. This proxy sits in front of both upstreams and records
# WHICH credential signed each request, so the tests can assert the access path
# itself rather than only its outcome.
```

**③ #41 본문 「4건을 ⬜로 내린 근거」가 이 문단을 축자로 담는다** — 「`opensearch.yaml` 은 security 플러그인이 꺼져 있어 서명된 요청과

받아준다 · 어떤 e2e 단언을 쓰더라도 「역할을 한 번도 assume 하지 않는 서버」에서 그대로 통과한다 → vacuous」와 정정 4 의 AC 이름
