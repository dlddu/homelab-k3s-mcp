## 제거 2줄 (24 → 22) — ① 코드 자체 재진술

```go
// FromEnv builds a Client from the AWS_CONFIG_* environment variables. It
// returns (nil, nil) when AWS_CONFIG_S3_BUCKET is unset, signalling that the
// integration is simply not configured (as opposed to misconfigured).
```

바로 아래 본문이 같은 것을 세 줄로 말한다:

```go
bucket := os.Getenv("AWS_CONFIG_S3_BUCKET")
if bucket == "" {
	return nil, nil
}
```

반환값·환경변수 이름·분기 조건이 전부 그 세 줄에 있다. 「not configured vs misconfigured」 의
대비도 **같은 함수의 두 분기**가 그대로 든다 — `bucket == ""` 는 `nil, nil` 로 빠지고,
바로 다음 `key == ""` 는 `fmt.Errorf(...)` 로 빠진다. 즉 「미설정은 에러가 아니고 잘못 설정은
에러다」가 코드의 형태 그대로다. 정책 「유지 대상 2」 의 마지막 항 —
**「1줄 뒤에 이어지는 문단이 시그니처나 `docs/prd-*.md` 를 되풀이하면 그 문단이 제거 대상」** —
에 정확히 걸린다.

남은 형태(관례 최소치 1줄 + 엔드포인트 계약 문단):

```go
// FromEnv builds a Client from the AWS_CONFIG_* environment variables.
//
// When AWS_CONFIG_S3_ENDPOINT is set, both the STS and S3 calls are routed to
// that endpoint with path-style S3 addressing.
```

**추가 0줄** — 첫 줄은 기존 문장에서 뒤따르던 `It` 만 떨어져 나갔고 새 낱말이 없다(새 주장 0건).
