## 유지 (사유 한 문장)

Go 관례 최소 doc(exported 식별자 첫 문장·패키지 주석)은 사유를 따로 대지 않는다. 아래는 필요성 시험으로 남긴 것이다.

- 서비스 표면 — 스트림 결과 타입의 상한·`TunnelClosed`·`Path`·`Method`/`Verb` 필드 사유(응답만 읽는 사람이 승인 맥락을 복원하지 못한다), `ProxyRef` 가 pod 전용이 아니라는 것, `Unavailable` 이 거부로 기록되는 이유.
- 컬렉션 삭제 — 네임스페이스가 값(포인터 아님)인 이유(가장 넓은 삭제를 표현 불가로 만든다), 결과가 요청이지 삭제 수가 아닌 이유, 클러스터 범위 종류 거부 이유, 선택자 무가공 이유, 이름 상한이 개수가 아닌 이름에 걸리는 이유, 빈 네임스페이스가 전 네임스페이스로 읽힌다는 상류 동작.
- 게이트 읽기 — `metadataAccept` 가 `application/json` 을 곁들이지 않는 이유(406 이 실패한 읽기이지 새어 나간 읽기가 아니다), 수작업 디코딩 이유, 전체 객체 응답 시의 처리, 시크릿 값이 프로세스에 들어오지 않았다는 단언의 이유, resourceVersion 없는 본문 거부.
- 리소스 계층 — 패치 타입 이름 체계·순서 안정성, CRD 용 코덱, 디스커버리 캐시의 1회 무효화, 종류 후보 순위(포함 일치·편집 거리·길이 비례 예산)와 그 테스트 사유, Error 이벤트 처리, `podLogsError` 가 JSON Status 본문을 읽는 이유, `objectNamespace` 단일 자리, scale 하위 리소스 디스커버리, 사전조건 위반 메시지에 apiserver 원문을 병기하는 이유, 삭제에 Preconditions 가 없는 이유, 403 처리.
- metrics — 미등록 도구 라벨, 게이트 대기 버킷, 전용 레지스트리, 거부·판정 전 거부가 지연 분포에서 빠지는 이유, 타이밍 테스트가 metrics 패키지 밖에 있는 이유.
