## 승계 ① 재판정 후보 둘의 소유자 — 이 패스가 세운 것

슬라이스 15 가 `main.go` 132–133 · 146–147 을 ① 재판정 후보로 넘기며 「소유자 후보는 `MetricsApp` doc 과 metrics 패키지 doc」이라 적었다.
이 패스가 그 둘을 물었고 결론은 **한 절만 첫째 줄**이다.

- `main.go buildMetricsServer` doc 의 「its own port so the ingress, which fronts LISTEN_ADDR only, never sees it」는 `MetricsApp`
  doc 의 「App is what the ingress reaches, and a path on it would be public the moment it existed」와 **같은 명제**다. 어느 쪽이
  소유자인가는 슬라이스 17 의 기준 — *그 명제가 구속하는 편집이 어느 파일에서 일어나는가* — 로 갈린다. 「경로가 아니라 포트여야 한다」를
  깨는 편집은 `App` 의 mux 에 `/metrics` 를 더하는 것이고 그것은 **`server.go` 에서 일어난다** ⇒ 소유자는 `MetricsApp` doc.
- 나머지(`METRICS_DISABLED` 가 노출만 끈다 · `METRICS_LISTEN_ADDR` 가 옮긴다 · `nil` 은 리스너 없음)는 `main.go` **고유분**이다.
  `buildMetrics` 132–133 의 「카운팅은 AC5 가 끄는 대상이 아니다」도 metrics 패키지 doc 의 「파생 지점 하나」와 다른 주장이다.

**이 패스는 그 한 절을 지우지 않는다** — `main.go` 는 원장 **#11**(`b036567ad0f0`)이고, 다른 행의 줄을 이 PR 이 지우면 그 행의
지문·줄 수가 함께 움직여 R2 가 두 행의 재판정을 요구한다. 소유자 판정만 여기 못박고 **그 행의 다음 재판정**으로 넘긴다.
