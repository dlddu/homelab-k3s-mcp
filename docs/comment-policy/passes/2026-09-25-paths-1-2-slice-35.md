## 다른 후보를 고르지 않은 이유 — 공유 사본 불변식

Go 서비스 패키지 행(`#2` opensearch · `#9` awsconfig · `#10` github)은 「선언 재진술」이 가장 짙어
보이지만, `Unavailable is a Service that fails every call with the same reason.` ·
`NewUnavailable builds …` · `Error is the error type returned by Service.` ·
`Unavailable reports whether this is the "not configured" kind — … (prd-event-log AC4).` ·
`errKind separates …` 다섯 블록이 **6개 패키지에 거의 바이트 동일 사본**으로 있다
(opensearch · awsconfig · github · grafana · k8s · sessionplatform = 원장 6행 · 404줄).
일부 행만 판정하면 같은 문장이 한 표면 안에서 갈린다 — 그 가족은 **6행을 한 슬라이스로** 묶어야
하고 이 슬라이스의 크기를 넘는다. 범위 밖으로 넘긴다.
