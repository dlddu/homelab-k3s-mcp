## 런타임 무영향

docstring 편집은 AST 안에서 일어나므로 슬라이스 21 이 세운 대로 **docstring 노드를 걷어낸 뒤의
AST 동등**을 썼다 — 세 파일 모두 편집 전후 동일. 기계가 읽는 선언(`검증 시나리오:`·`실행 대상:`·
`실행 순서:`·`병렬 레인:`)은 세 파일 모두 축자로 살아 있고, `py_compile` 통과.
`internal/`·`main.go`·`scripts/`·`tests/k8s/`·다른 `tests/integration/` **0바이트**.

**자매 축 무영향** — `check_mock_policy` · `check_ac_mapping` 두 출력 md5 가 base 와 동일.
`check_doc_inventory.py` 는 이 패스 문서 1건만큼 움직인다(80 → 81 · 정책 40 → 41).

**게이트를 양방향으로 굴렸다** — 고친 트리 rc=0(`복원경로 ③④ 판정 22/32행(잔량 10)` ·
`docstring 2065줄` 축자 확인) / 원장만 부모 값으로 되돌린 트리 **rc=1 7건**: **R6** 여섯(세 행의
줄 수 셋 + 지문 셋)과 **R8**(합계 2,073 + 잔량 0 != 실측 2,065). 슬라이스 23 의 관측이 재현된다 —
**잔량 마커만으로는 제거를 지키지 못하고 R6·R8 이 함께 지킨다.**
