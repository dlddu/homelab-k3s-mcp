## 제거 4줄 — 전부 ① 코드 자체 재진술

### ⑴ `opensearch.go` `162–164` → `162` 1줄 (−2)

```go
// FromEnv builds a Client from the OPENSEARCH_* environment variables. It
// returns (nil, nil) when OPENSEARCH_ENDPOINT is unset, signalling that the
// integration is simply not configured (as opposed to misconfigured).
```

바로 아래 네 줄이 그 명제를 **반환값·변수명·분기조건째** 든다:

```go
endpoint := os.Getenv("OPENSEARCH_ENDPOINT")
if endpoint == "" {
	return nil, nil
}
roleARN := os.Getenv("OPENSEARCH_ROLE_ARN")
if roleARN == "" {
	return nil, fmt.Errorf("OPENSEARCH_ROLE_ARN is required when OPENSEARCH_ENDPOINT is set")
}
```

「not configured **vs** misconfigured」 대비까지 같은 함수의 다음 분기가 들고, 그 오류 문면이 주석
문장과 축자로 겹친다. 남긴 `162` 는 정책이 유지 예시로 명문화한 **이름으로 시작하는 1줄**이다.
둘째 문단 `164–167`(`OPENSEARCH_REGION` 이 서명 리전을 겸한다 · `OPENSEARCH_STS_ENDPOINT` 라우팅)은
**상류 동작**이라 슬라이스 37 이 `awsconfig` 의 같은 자리 문단을 남긴 판정을 승계한다.

### ⑵ `sessionplatform.go` `194–198` → `194–196` 3줄 (−2)

// http://control-plane.session-platform.svc.cluster.local). It returns
// (nil, nil) when the variable is unset, signalling that the session platform

## 가족 밖의 `(nil, nil)` 사본 하나 — `gatekeeper.go`, 고의로 남긴다

전수 그렙(`^\s*//.*\(nil, nil\)`)은 tip 에서 **세 건**을 낸다. 둘은 이 패스가 지우고, 셋째는
`internal/gatekeeper/gatekeeper.go:123–125`(원장 행 `#24`, ①② 미판정)다:

```go
// FromEnv reads the gate configuration. It returns (nil, nil) when the gate is
// not configured at all, which the caller turns into a refusing gate rather
// than a fatal error.
```

**이 패스의 ① 논거는 여기에 그대로 적용되지 않는다** — 두 가지가 다르다:

1. `#24` 는 이 사족 가족(`Unavailable()` 축 여섯 행)에 **속하지 않는다**. 이 패키지는 통합
   클라이언트가 아니라 게이트 설정이고 `Unavailable()`·`errKind` 사본이 없다.
2. 둘째 절 「**which the caller turns into a refusing gate rather than a fatal error**」는
   *호출자*의 처리를 말하는 **교차 패키지 진술**이라 이 파일의 코드로 복원되지 않는다. 그리고
   `#24` 의 2026-09-13 ③④ 판정문은 이 자리를 **이름을 들어 유지**했다 — 「`123–125` `FromEnv`
   `(nil, nil)` 계약 ↔ #73 「게이트 설정이 없는 현재 배포에서도 서버는 정상 기동」 — 반환값 계약
   → 유지」.

첫 문장의 `(nil, nil)` 절만 떼는 **절 단위 좁히기**는 가능해 보이지만, 그러려면 `#24` 125줄 전체를
①② 로 판정하고 서 있는 유지 판정을 그 논거 하나에 대해서만 좁혀야 한다 — 슬라이스 하나의 몫이다.
**「애매하면 남긴다」를 적용해 이 패스는 건드리지 않고, 후속 후보로 이름째 등재한다.**
⇒ 다음 패스가 이 패스의 ① 논거를 `#24` 로 **자동 확장해 읽지 말 것**. 위 두 판별식을 먼저 재라.
